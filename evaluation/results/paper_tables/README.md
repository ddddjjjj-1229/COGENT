# Paper Tables

The previously committed aggregate tables were generated by an older post-processing
pipeline that applied fixed ablation penalties and score-order calibration. They are
intentionally not retained as reported results.

To produce tables from the current scoring pipeline, run the evaluation with the
canonical 200-case benchmark and then run:

```bash
python scripts/export_paper_tables.py --summary results/full_200/summary.json --mode main
python scripts/export_paper_tables.py --summary results/full_200/content_summary.json --mode content
```

The exporter now writes the values present in the summary files without applying
minimum-score floors, fixed penalties, or post-hoc method ordering.
